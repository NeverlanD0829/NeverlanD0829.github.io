[easy-paper-reader](https://github.com/NeverlanD0829/easy-paper-reader) 是一个把论文 PDF 整理成长篇中文解读的工具。它沿着论文的章节组织内容，提取图表，并检查文章有没有说明贡献背后的实验依据。本文根据仓库公开 README 整理，具体用法以仓库当前版本为准。

## 一篇解读需要留下哪些证据

读完论文之后，除了知道作者提出了什么，还需要能找到支撑这些说法的实验。项目围绕几件事组织阅读过程：

- **贡献和证据对应**。每项贡献都需要说明依据；缺少消融实验的说法，不能被标记为有充分实验支持。
- **逐张查看图像**。从 PDF 裁出图表，结合图注、正文引用和图像本身解释结果。
- **保留原文章节结构**。中文章节与原论文对应，方便回到原文检查。
- **检查中文表达**。单独检查重复句式、模板化结构和影响阅读的语言痕迹。

这些检查帮助发现遗漏，文章是否正确仍然需要结合论文人工核对。

## 从 PDF 到文章

流程首先提取逐页文本、章节和图表清单，渲染页面，再按图注附近的位置计算裁切范围。之后整理贡献与证据、建立中英章节对应关系，结合裁出的图像撰写解释。

最终产物包括文章、图像和中间记录。保留这些文件，便于追溯一张图来自哪里、一项判断依据什么实验。

| 阶段 | 主要产物 |
| --- | --- |
| 文本和结构提取 | 逐页文本、章节大纲、图表清单 |
| 图像裁切 | 裁切计划、图片与来源记录 |
| 内容组织 | 贡献与证据、章节映射、正文 |
| 检查与导出 | 内容检查、表达检查、适合粘贴到编辑器的 HTML |

英文大纲和需要重点解释的表格、公式清单，需要用户确认后继续，避免一开始识别错了结构，影响整篇文章。

## 内容检查与表达检查

项目提供两个独立的检查脚本。内容检查关注图表是否覆盖、章节是否对应、贡献是否绑定证据；表达检查关注中文句式、段落节奏和模板化表达。

仓库中的示例可以用下面的命令检查：

```bash
python3 scripts/audit_article.py examples/vpp2/article.md
python3 scripts/check_tone.py examples/vpp2/article.md
```

这些检查定位的是可以由规则识别的问题。它们不能替代对实验设计、论证过程和论文结论的判断。

## 使用前需要知道的限制

当前流程依赖 PDF 的文本层。扫描版论文需要先做 OCR；没有书签、版式特殊的论文，可能需要手动修正大纲。双栏排版中的跨栏图表也可能需要调整裁切位置。

表达检查的规则面向中文技术解读，换到其他写作领域时，需要重新调整。
